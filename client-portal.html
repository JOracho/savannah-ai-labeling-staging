Savannah administration

Create a Supervisely project

Creates a new image project in Savannah's Supervisely workspace and adds its access link to the selected client account in this portal. Leave Client account UUID blank to create a test project under your administrator account.

Configure the client's annotation tool

Choose whether Savannah provides the workspace or the client uses their own platform. For client-owned tools, add the platform name and secure workspace link. Only administrators can change these settings.

BYOT access is granted by the client in their own platform. Savannah will not ask for or store the client's platform password or API key.

CVAT connection

The CVAT connector is prepared in staging. It will be testable after the CVAT API token is added securely to Neon Function secrets.

CVAT LiDAR task setup

For a point-cloud trial, create the 3D task directly in CVAT, then register its task ID, job ID and frame range in Savannah's assignment form. The old automated CVAT form only handled image uploads and is disabled for this LiDAR test.

Open CVAT

The first test task uses one label named “object”. You can change labels later when we configure the real annotation workflow.

Client deliverables

The Neon upload route for administrator-published deliverables is being finalized. This control is temporarily hidden in staging; approved BYOT files and managed annotation review remain separate workflows.

Manage annotators

Annotators first create a Savannah account using the sign-up tab. Enter their registered email below to activate annotator access. They must sign out and back in after activation.

Activate a reviewer

The reviewer must first create a Savannah account. Enter their registered email to grant review-only access.

Activate a team lead

The team lead must first create a Savannah account. Enter their registered email to grant access to assignments allocated to them.

Assign a project

Workload policy: each annotator can have one active project at a time. A new project can be allocated after the current work is submitted. Submitted work may remain with the reviewer while the annotator receives another batch. Assignments grant portal visibility only; invite the annotator's individual account into the relevant annotation workspace.

Assignment review

Review work submitted by annotators. Approve completed work or request corrections.
